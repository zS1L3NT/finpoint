# Drill-down URL state

The Drill-down explains a Dashboard number while preserving the month, year, scope and scroll position. Store its selection in the `drill` search parameter rather than component state so links survive reloads and browser Back restores the previous selection. Each selection and explicit close uses `router.push` with `scroll: false`; Back after opening closes the panel. Invalid selections render no panel and produce no error.

The shipped grammar is `day:YYYY-MM-DD`, `category:<id>[:YYYY-MM]`, `budget:<id>[:YYYY-MM]`, and `month:YYYY-MM`. Category selections may contain comma-separated IDs. Month and year describe the Dashboard; an optional selection month describes the drill's period without changing that Dashboard context. Keep the existing `scope` parameter. Opening or closing clears `focus`; `focus=record:<id>` expands one Record; `focus=statement:<id>` replaces the body with its Allocations and account breadcrumb. Each focus change pushes history, so browser Back restores the preceding expansion. The panel Back action returns to the originating Record when known, or to the selection for a shared Statement link. Allocation rows in the Statement view link to Record pages; they do not create nested accordions. Reloads preserve focus. Invalid or missing focus targets close silently.

At xl the panel docks at 420px and the main column narrows with the shared smooth spring. Below xl it uses a bottom sheet. Closing restores focus to the opener without scrolling; selecting another mark reuses the panel. Component state alone would lose shareable context, while navigating to Records would remove the chart that supplied the question.

Category and trend rows display gross spending, while Biggest changes displays net spending. `category-gross:<ids>[:YYYY-MM]` preserves the gross measure in shared links; `category:<ids>[:YYYY-MM]` includes refunds. Month selections show gross spending. All these chart components use one `onDrill(selection)` callback (D4). A Monthly Budget selection includes refunds and its month's comparison amount. Forecast legend totals use `budget:all`, and unbudgeted spending uses `budget:unbudgeted`. A budget card opens the panel (D2); changing dashboard scope is an explicit action inside it.

`drill=largest` opens all Spending Records for the month and scope in descending absolute amount order. The card previews five. Open in Records preserves `sort=amount_desc`; Records also supports `amount_asc`. Amount ordering precedes pagination and disables day grouping so the visible order remains global.


`drill=compare:<category-id>` opens Biggest changes in comparison mode, retaining Dashboard month and scope. The baseline uses the included `COMPARISON_MONTHS` window, rather than the longer trend window. Current months use the same elapsed days; other months use full months. Both columns show net Spending Records, while the historical headline is their per-month average. Uniqueness labels compare exact Record titles across the two periods; they do not infer recurring activity. Missing history displays “No comparison”.
